## 本次已修复

1. 本地/查询课表统一安全渲染，转义课程和备注，修复未闭合 class 属性；每天课程列表不再使用 HTML 插值。
2. 编辑弹窗按纯文本读写，避免 `</textarea>` 等内容注入；重复打开/保存/关闭不会创建重叠弹窗、重复提交或二次移除节点。Android 返回处理关闭后恢复。
3. 共用课表渲染函数减少重复代码及原生存储读取（完整课表且首个备注非空时由 88 次降为 43 次）。清除备注后不残留旧内容，并保留可编辑空备注格。
4. 查询/重置检查空数组、错误对象与字段类型；失败不覆盖缓存，缺失/null 单元格不存成 `undefined`/`null` 字样。取消更新或请求失败不清除更新提醒，验证成功才清除。
5. 不再把登录密码写入 localStorage，登录页及主页面清除旧版遗留密码；保留邮箱记忆，不再自动填密码。
6. 周数按当地日历日期计算，开学日零点为第一周，七天后为第二周，规避夏令时误差；非法学期日期不覆盖有效缓存。
7. 微信小程序处理班级为空、学院切换索引越界、HTTP/返回数据错误、旧请求覆盖、离页回调；提供加载/错误/重试状态并正确编码查询参数。公开查询不再调用无用的用户资料授权。
8. 增加零第三方依赖测试和应用代码语法检查，保留旧 APP 架构与接口地址。

## 未解决的高优先级风险（不能据此认为已全面安全）

### P0：凭据和发布配置

- `src/manifest.json` 中有历史第三方 `appsecret` 硬编码。**本次没有删除、替换或验证其有效性**；删除会影响旧原生打包/分享集成，且不能消除 Git 历史泄露。
  发布前应由有权限的账号在相应服务轮换/撤销这些密钥，再改为不提交的本地打包配置，并审查历史访问记录。
  报告和差异补丁不包含密钥值；交付包不含原始 manifest 或整个仓库快照。
- 登录、注册、密码修改等旧接口仍使用 HTTP，部分以 GET 参数传密码；更新描述/下载链路也使用 HTTP。
  **本次没有盲改成 HTTPS/POST**：仓库没有对应后端契约、可用证书、会话/令牌迁移或升级签名方案；直接更换协议/方法可能使旧客户端失效。
  需优先确认受控 HTTPS 服务、服务端 POST/会话校验以及签名更新，再迁移客户端。移除密码缓存不解决传输风险。

### P1：维护性与运行环境

- 多个同步 AJAX (`async: false`) 仍可能卡住主线程；账户流程需要连同服务端状态/错误契约分步异步化，不宜机械全局替换。
- 其他信息流/搜索页面仍有字符串拼接 HTML，本次安全加固范围是课程表、课程编辑和 `Tohtml`，不是全站 XSS 审计。
- 工具目录有历史同步/数据导入代码，未运行、未连数据库、未部署；需单独审查认证、输入与 SQL 处理。
- `kb-web` 的完整构建在 Node 24 下仍失败：Node Sass 4 不支持当前运行时，旧 UglifyJs 不能解析部分当前解析出的 vendor；已修“有编译错误仍退出 0”的误报。
  需要单独的依赖迁移/锁版本工作，而不是用 `--force` 掩盖问题。
- 网页校历仍配置为 2017 学期。没有可靠现行学校学期数据，不自行猜测更新。
